## 2. Kingdom layout (relative coordinates, +z south, y 0 = plaza level, world y = 150)

```
                 N  (mountains, back of the caldera)
        ┌──────────────────────────────────────────┐
        │  Hall of Champions   CITADEL   Hall of    │  terrace y+20, z -40..-175
        │  (west wing)    keep + spires  Ascension  │
        │          Royal Treasury (under)   (east)  │
        ├────────── double grand staircase ─────────┤  z -40..-18
        │ Merchant         MOLTEN PLAZA     Blacksmith│  y+4 terraces, x ±58..140
        │ District        (0,30) r 46        Quarter │
        └───────────────────  road ─────────────────┘
                     DRAGON GATE (z +170) -> bridge -> wilderness
```
Navigation: spawn on the plaza, avenue north to the double staircase, treasury doors at the bottom between the flights,
the citadel gate on top. Merchant and Blacksmith terraces east and west of the plaza, reached by short stairs. Roads
run from the plaza south to the Dragon Gate.

## 3. Interaction coordinates

spots, NPC spots, gate). Re-pointing the existing features (`DistrictLife.CRATE_SPOTS`, `KingdomLayout.HALL`, stalls,
warps, protection radius) at them is the integration step and happens only after staging tests.
